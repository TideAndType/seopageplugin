# AEO / AI Citation Expert

TideOrbit treats Answer Engine Optimization (AEO) as an extension of sound search/content architecture, not a bag of "AI SEO" tricks.

## What TideOrbit measures

The AEO Expert audits:

- public WordPress indexability
- robots.txt access for Googlebot, Bingbot and OAI-SearchBot
- direct answer structure
- descriptive/question-based headings
- first-party evidence
- authoritative external source support
- entity clarity
- structured data that matches visible content
- author/publisher identity
- freshness
- useful textual depth

## What TideOrbit does not fake

An **AEO Readiness** score is a TideOrbit diagnostic. It is not a ranking score, citation probability, or claim that an AI system cited the site.

Actual citation counts/queries require real provider data. Until an integration supplies that measurement, TideOrbit shows no fabricated citation metrics.

## Platform-grounded rules

### Google AI features

Normal Google Search eligibility remains foundational. TideOrbit does not recommend a special "AI schema" or an AI-only text file as a requirement for Google AI features.

### ChatGPT Search

OAI-SearchBot access is audited separately from GPTBot/training controls. Public pages intended for ChatGPT Search discovery should not block OAI-SearchBot.

### Bing / Copilot ecosystem

Bing crawl access remains foundational. Where a real Bing AI-performance integration is available, citation data should be treated as observed provider data rather than converted into a made-up ranking score.

## Content generation

TideOrbit briefs and drafts are AEO-aware:

- answer important questions directly before expanding
- make important entities explicit
- plan the evidence needed for factual claims
- prefer first-party proof and authoritative primary sources
- never invent source URLs, studies, quotes or statistics
- avoid thin FAQ stuffing
- never promise citations from schema, llms.txt, keyword repetition or formatting
